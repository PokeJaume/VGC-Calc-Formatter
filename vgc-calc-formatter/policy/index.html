Privacy Policy

Last updated: August 16, 2026

Summary

VGC Calc Formatter ("the add-on") is a Google Docs add-on that helps format and organize Pokémon VGC calculation notes within the active document. This policy explains which Google data the add-on accesses, why it is needed, how it is protected, with whom (if anyone) it is shared, and how to request access or deletion.

Google data accessed by this application

The add-on requests only the permissions necessary to provide its in-document features. Specifically:

  • Active document content — via the documents.currentonly scope the add-on can read and modify the content of the Google Docs document the user currently has open, only when the user triggers an explicit formatting or edit action from the add-on UI.
  • User preferences — via script.storage the add-on stores formatting preferences (for example palettes, color thresholds, style options) in Apps Script PropertiesService; these preferences are stored in the Google project environment associated with the add-on and are used to remember the user's settings.
  • Locale / regional settings — via script.locale the add-on obtains the user's locale/language to adapt formats and messages.
  • Container UI — via script.container.ui the add-on displays and controls its sidebar and dialogs inside Google Docs.

The add-on does not request access to other documents or broader Drive access; access is limited to the current document by documents.currentonly.

Use of data

Data obtained via Google APIs is used only to provide the visible and explicit functions of the add-on:

  • Read the selected content or the active document to analyze and apply the formatting requested by the user (for example, convert calculation blocks into tables or apply styles).
  • Save and retrieve user formatting preferences so the add-on provides a persistent, personalized experience across sessions.
  • Adapt the UI and behavior according to the user's locale settings.

Document content is processed only to perform the action requested by the user and is not used for advertising, selling data, profiling outside the service, or training AI models.

VGC Calc Formatter's use of information obtained via Google APIs complies with the Google API Services User Data Policy, including the Limited Use requirements.

Data sharing and transfer

VGC Calc Formatter does not sell, rent, or share document content or other Google data obtained via the Google APIs with third parties for commercial purposes.

The add-on does not transmit document content to external servers or third-party services for processing. Code execution for the add-on runs in Google Apps Script within Google's infrastructure, except for public static resources required for the UI (for example logo images loaded from public URLs).

Security and data protection

Reasonable measures are applied to protect data handled by the add-on:

  • The add-on runs on Google Apps Script infrastructure and relies on Google Workspace protections and access controls (HTTPS, OAuth permission controls, and script environment isolation).
  • User preferences stored in PropertiesService remain in the Google project environment associated with the Apps Script project and are not publicly exposed.
  • The developer does not request or store Google passwords or external authentication credentials.

Retention and deletion

VGC Calc Formatter does not retain permanent copies of processed Google Docs content. Document content is used in memory during execution of the requested action and is not stored on external servers.

User preferences stored in PropertiesService are kept only as long as necessary to provide the add-on's features (for example to persist settings across sessions). Users may request deletion of these preferences by contacting the developer at pokejaumes@gmail.com.

To request data deletion or for any privacy-related inquiries, contact the developer at pokejaumes@gmail.com. Requests will be handled in a timely manner and in accordance with applicable law.

Test credentials and reviewer instructions

This add-on does not require separate test credentials: it uses Google sign-in (OAuth) to authorize the requested permissions.

Instructions for reviewers:

  1. Open Google Docs with a Google account.
  2. Install or deploy the add-on (from the Marketplace or as a deployed editor add-on draft).
  3. Go to Extensions → VGC Calc Formatter and open the sidebar.
  4. On first open, authorize the OAuth flow and display the consent screen with requested permissions; expand "Show all services" if present and leave the scopes visible on screen.
  5. Create or open a test document containing a block of VGC calculation text, select the block and run the formatting action to demonstrate documents.currentonly.
  6. Change a preference in the sidebar, close and re-open the add-on to verify the preference persists (demonstrates script.storage).

OAuth consent and scope usage

During authorization the user will see the Google consent screen and the requested scopes. The add-on requests the following minimal, justified scopes:

  • documents.currentonly: required to read and write changes to the active document when the user requests a formatting operation.
  • script.storage: required to store user preferences in PropertiesService.
  • script.locale: required to adapt formats and texts to the user's locale and regional settings.
  • script.container.ui: required to display the sidebar and UI controls inside Google Docs.
