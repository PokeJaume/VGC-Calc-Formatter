Política de Privacidad

Última actualización: 16 de agosto de 2026

Resumen

VGC Calc Formatter ("el complemento") es un complemento para Google Docs que ayuda a formatear y organizar notas de cálculo VGC dentro del documento activo. Esta política explica qué datos de Google accede el complemento, con qué fin, cómo se protegen, con quién (si alguien) se comparten y cómo solicitarlos o eliminarlos.

Datos de Google a los que accede la aplicación

El complemento solicita únicamente los permisos necesarios para ejecutar sus funciones dentro del documento activo. En concreto:

  • Contenido del documento actual — mediante el permiso documents.currentonly el complemento puede leer y modificar el contenido del documento de Google Docs que el usuario tiene abierto, solo cuando el usuario ejecuta una acción explícita de formateo o edición desde la interfaz del complemento.
  • Preferencias del usuario — mediante script.storage el complemento almacena preferencias de formato (por ejemplo paletas, umbrales de color, opciones de estilo) en PropertiesService de Apps Script; estos datos se guardan en el entorno de Google asociado al complemento y se usan para recordar la configuración del usuario.
  • Configuración regional — mediante script.locale el complemento obtiene la configuración regional/idioma necesaria para adaptar formatos y mensajes.
  • Interfaz dentro del contenedor — mediante script.container.ui el complemento muestra y controla la barra lateral y los diálogos dentro de Google Docs.

El complemento no solicita permisos para acceder a otros documentos ni a datos fuera del documento activo con documents.currentonly.

Uso de los datos

Los datos obtenidos mediante las APIs de Google se usan exclusivamente para proporcionar las funciones visibles y explícitas del complemento:

  • Leer el contenido seleccionado o del documento activo para analizar y aplicar el formato solicitado por el usuario (por ejemplo, convertir bloques de cálculo a una tabla o aplicar estilos).
  • Guardar y recuperar preferencias de formato del usuario para ofrecer una experiencia persistente y personalizada entre sesiones.
  • Adaptar la interfaz y el comportamiento según la configuración regional del usuario.

El contenido de los documentos se procesa únicamente para ejecutar la acción solicitada por el usuario y no se utiliza para publicidad, venta de datos, creación de perfiles fuera del servicio, ni para entrenar modelos de IA.

El uso que VGC Calc Formatter hace de la información recibida mediante las APIs de Google cumple con la Google API Services User Data Policy, incluidos los requisitos de Limited Use.

Compartición y transferencia de datos

VGC Calc Formatter no vende, alquila ni comparte el contenido de los documentos de Google Docs ni otros datos obtenidos mediante las APIs de Google con terceros para fines comerciales.

El complemento no transmite el contenido de los documentos a servidores externos ni a servicios de terceros para su procesamiento. La ejecución del código del complemento se realiza mediante Google Apps Script, dentro de la infraestructura de Google, salvo recursos estáticos públicos necesarios para la interfaz, como imágenes de logotipo.

Seguridad y protección de datos

Se aplican medidas razonables para proteger los datos tratados por el complemento:

  • El complemento se ejecuta sobre la infraestructura de Google Apps Script y utiliza las protecciones y controles de acceso de Google Workspace (HTTPS, control de permisos OAuth y aislamiento en el entorno del script).
  • Las preferencias de usuario almacenadas en PropertiesService permanecen en el entorno de Google asociado al proyecto Apps Script y no se publican ni se exponen públicamente.
  • El desarrollador no solicita ni almacena contraseñas de Google ni credenciales de autenticación externas.

Retención y eliminación de datos

VGC Calc Formatter no conserva permanentemente copias del contenido de los documentos de Google Docs procesados. El contenido del documento se utiliza en memoria durante la ejecución de la acción solicitada y no se almacena en servidores externos.

Las preferencias del usuario almacenadas en PropertiesService se conservan mientras sean necesarias para proporcionar las funciones del complemento (por ejemplo, persistir configuraciones entre sesiones). El usuario puede solicitar la eliminación de estas preferencias contactando con el desarrollador en pokejaumes@gmail.com.

Para solicitar la eliminación de datos o para cualquier consulta relacionada con la privacidad, contacte al desarrollador en pokejaumes@gmail.com. Las solicitudes serán atendidas en un plazo razonable y conforme a la legislación aplicable.

Credenciales de prueba e instrucciones para revisores

Este complemento no requiere cuentas ni credenciales separadas: utiliza el inicio de sesión de Google (OAuth) para autorizar los permisos solicitados.

Instrucciones para revisar el complemento:

  1. Abrir Google Docs con una cuenta de Google.
  2. Instalar o desplegar el complemento (desde Marketplace o como proyecto de editor desplegado en draft).
  3. Ir a Extensiones → VGC Calc Formatter y abrir la barra lateral.
  4. Al abrir por primera vez, autorizar el flujo OAuth y mostrar la pantalla de consentimiento con los permisos solicitados; expandir "Show all services" si aparece y dejar los scopes visibles en pantalla.
  5. Crear o abrir un documento de prueba con un bloque de texto de cálculo VGC, seleccionar el bloque y ejecutar la acción de formateo para demostrar documents.currentonly.
  6. Modificar una preferencia en la barra lateral, cerrar y reabrir el documento para verificar que la preferencia persiste (demuestra script.storage).

Consentimiento OAuth y uso de scopes

Durante la autorización el usuario verá la pantalla de consentimiento de Google y los scopes solicitados. El complemento solicita los siguientes scopes mínimos y justificados:

  • documents.currentonly: necesario para leer y aplicar cambios en el documento activo cuando el usuario lo solicita.
  • script.storage: necesario para guardar preferencias de usuario en PropertiesService.
  • script.locale: necesario para adaptar formatos y textos según la configuración regional del usuario.
  • script.container.ui: necesario para mostrar la barra lateral y controles dentro de Google Docs.
