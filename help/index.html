VGC Calc Formatter — Help

A quick guide to getting started with the add-on.

1. Install the add-on

Install VGC Calc Formatter from the Google Workspace Marketplace or the distribution source you received.

2. Open a Google Doc

Open a document where you want to format Pokemon VGC calculation notes.

3. Open the add-on

Go to Extensions → VGC Calc Formatter to open the sidebar or available actions.

4. Use the available tools

Select the content you want to process and use the formatting actions from the add-on interface.
